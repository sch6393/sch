    변환

    iconv -f UTF8 -t CP932 CCC_UTF8.csv > CCC_CP932.csv

    UTF8을 CP932로 변환


    iconv: illegal input sequence at position 0 라는 메시지가 뜨는 경우

    iconv -c -f UTF8 -t CP932 CCC_UTF8.csv > CCC_CP932.csv

    -c 옵션을 추가 (내용 손실이 있을 수 있음) ➞ 손실을 없애려면 nkf를 사용
